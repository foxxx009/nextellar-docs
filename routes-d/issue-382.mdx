# Funding Testnet Accounts

Before you can interact with the Stellar testnet, your account must be funded. On testnet, this is done using Friendbot, a service that provides free test lumens (XLM) to developers.

This guide walks through the process of requesting testnet funds, understanding expected delays, and verifying your account is ready to use.

---

## 1. Request Funds via Friendbot

Friendbot is a faucet for the Stellar testnet. You can request funds by providing your public key.

### Using the Stellar CLI

The easiest way to fund an account is with the Stellar CLI:

```bash
stellar keys fund alice --network testnet
```

### Using HTTP/curl

Alternatively, you can call the Friendbot API directly with your account's public key (address):

```bash
curl "https://friendbot.stellar.org/?addr=YOUR_PUBLIC_KEY"
```

Replace `YOUR_PUBLIC_KEY` with the actual address (starting with a `G`).

---

## 2. Expected Delays

While Friendbot usually funds accounts within a few seconds, **expect delays during periods of high network congestion or API rate limiting**. 

- If the request takes longer than a few seconds, the CLI or API might timeout, but the transaction may still be in the queue.
- If you receive a `429 Too Many Requests` error from Friendbot, wait a few minutes and try again. 
- Wait at least 10-15 seconds before retrying to prevent overwhelming the faucet.

---

## 3. Verify Account Creation

An unfunded keypair does not exist on the Stellar ledger. Funding it through Friendbot executes a `create_account` operation.

Verify that the account has been funded and exists on the network by querying Horizon:

```bash
curl -s "https://horizon-testnet.stellar.org/accounts/YOUR_PUBLIC_KEY" \
  | jq '{ id, balances }'
```

If the funding was successful, you will see a JSON response containing your balances:

```json
{
  "id": "G...",
  "balances": [
    {
      "balance": "10000.0000000",
      "asset_type": "native"
    }
  ]
}
```

If the account is not yet funded or the request is still pending, this same query will return a `404 Not Found` error.

---

## Summary

- Use `stellar keys fund` or the `https://friendbot.stellar.org` endpoint.
- Account for potential delays during heavy testnet usage.
- Use Horizon to confirm the `native` balance shows 10,000 XLM.
