# Complete WalletConnect Integration Example

WalletConnect v2 enables seamless mobile wallet authentication and transaction signing for Web3 dApps on Stellar. This tutorial covers setting up project metadata, initializing `@walletconnect/sign-client`, establishing user sessions, and executing raw Stellar transaction signing requests.

---

## 1. Project Metadata Configuration

WalletConnect requires dApp metadata for user identification during connection requests:

```typescript
export const dAppMetadata = {
  name: 'Nextellar DApp',
  description: 'Production-ready Stellar dApp scaffolded with Nextellar',
  url: 'https://app.nextellar.dev',
  icons: ['https://app.nextellar.dev/icon.png'],
};
```

---

## 2. WalletConnect Client Initialization

Initialize the `SignClient` with your WalletConnect Cloud Project ID (obtained from [cloud.walletconnect.com](https://cloud.walletconnect.com)):

```typescript
import SignClient from '@walletconnect/sign-client';

let signClient: SignClient;

export async function initWalletConnect() {
  signClient = await SignClient.init({
    projectId: process.env.NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID!,
    metadata: dAppMetadata,
  });

  return signClient;
}
```

---

## 3. Session Establishment Flow

Connect to Stellar supported wallets using the standard `stellar` namespace proposal:

```typescript
export async function connectWalletConnect(signClient: SignClient) {
  try {
    const { uri, approval } = await signClient.connect({
      requiredNamespaces: {
        stellar: {
          methods: ['stellar_signTransaction'],
          chains: ['stellar:pubnet', 'stellar:testnet'],
          events: ['accountsChanged', 'chainChanged'],
        },
      },
    });

    if (uri) {
      // Display QR Code modal to the user using uri
      console.log('Open QR Code modal with URI:', uri);
    }

    const session = await approval();
    const account = session.namespaces.stellar.accounts[0]; // format: "stellar:testnet:G..."
    const publicKey = account.split(':')[2];

    return { session, publicKey };
  } catch (error) {
    console.error('WalletConnect connection failed:', error);
    throw error;
  }
}
```

## 4. Transaction Signing Sample

Request the connected WalletConnect session to sign an XDR transaction envelope:

```typescript
export async function signTransactionWithWalletConnect(
  signClient: SignClient,
  sessionTopic: string,
  xdrBase64: string,
  networkPassphrase: string
): Promise<string> {
  const result = await signClient.request({
    topic: sessionTopic,
    chainId: 'stellar:testnet',
    request: {
      method: 'stellar_signTransaction',
      params: {
        xdr: xdrBase64,
        networkPassphrase,
      },
    },
  });

  // Returns signed XDR payload string from wallet
  return result as string;
}
```

## 5. Event Handling & Disconnection

Listen for account switching and disconnect events to update React component state:

```typescript
export function setupSessionListeners(signClient: SignClient, topic: string) {
  signClient.on('session_delete', ({ topic: deletedTopic }) => {
    if (deletedTopic === topic) {
      console.log('User disconnected session');
      // Reset local dApp auth state
    }
  });
}

export async function disconnectSession(signClient: SignClient, topic: string) {
  await signClient.disconnect({
    topic,
    reason: {
      code: 6000,
      message: 'User logged out from dApp UI',
    },
  });
}
```

## Complete React Hook Integration Summary

```typescript
import { useState, useEffect } from 'react';

export function useWalletConnect() {
  const [address, setAddress] = useState<string | null>(null);
  const [session, setSession] = useState<any>(null);

  const connect = async () => {
    const client = await initWalletConnect();
    const { session, publicKey } = await connectWalletConnect(client);
    setSession(session);
    setAddress(publicKey);
  };

  return { address, session, connect };
}
```
