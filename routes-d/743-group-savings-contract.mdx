# Group Savings Contract Tutorial

A group savings contract (also called a rotating savings club or tontine in some cultures) lets a fixed group of members make regular contributions to a shared pool. This tutorial builds a Soroban implementation with contribution tracking, withdrawal rules, and a simple governance mechanism for accepting or removing members.

---

## Contract Design

| Feature | Implementation |
|---------|---------------|
| Membership | Admin-managed allowlist of member addresses |
| Contributions | Any member can deposit at any time |
| Withdrawals | Member withdraws their own share; admin-approved early withdrawal |
| Governance | Admin can add/remove members; member vote required for large withdrawals |

---

## Data Model

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, token, Address, Env, Symbol, Vec};

#[contracttype]
pub enum DataKey {
    Admin,
    Token,
    Members,
    Balance(Address),  // member → total contributed
    TotalPool,
}
```

---

## Initialization

```rust
#[contract]
pub struct GroupSavings;

#[contractimpl]
impl GroupSavings {
    pub fn initialize(env: Env, admin: Address, token: Address) {
        assert!(!env.storage().instance().has(&DataKey::Admin), "already initialized");
        env.storage().instance().set(&DataKey::Admin, &admin);
        env.storage().instance().set(&DataKey::Token, &token);
        env.storage().instance().set(&DataKey::TotalPool, &0_i128);
        env.storage().instance().set(&DataKey::Members, &Vec::<Address>::new(&env));
    }
```

## Membership Management

```rust
    pub fn add_member(env: Env, caller: Address, member: Address) {
        caller.require_auth();
        let admin: Address = env.storage().instance().get(&DataKey::Admin).unwrap();
        assert!(caller == admin, "only admin can add members");

        let mut members: Vec<Address> = env.storage().instance().get(&DataKey::Members).unwrap();
        assert!(!members.contains(&member), "already a member");
        members.push_back(member.clone());
        env.storage().instance().set(&DataKey::Members, &members);

        env.events().publish((Symbol::new(&env, "member_added"), member), ());
    }

    pub fn remove_member(env: Env, caller: Address, member: Address) {
        caller.require_auth();
        let admin: Address = env.storage().instance().get(&DataKey::Admin).unwrap();
        assert!(caller == admin, "only admin can remove members");

        let balance: i128 = env.storage().instance()
            .get(&DataKey::Balance(member.clone()))
            .unwrap_or(0);
        assert!(balance == 0, "member has outstanding balance; withdraw first");

        let mut members: Vec<Address> = env.storage().instance().get(&DataKey::Members).unwrap();
        let idx = members.iter().position(|m| m == member).expect("not a member");
        members.remove(idx as u32);
        env.storage().instance().set(&DataKey::Members, &members);

        env.events().publish((Symbol::new(&env, "member_removed"), member), ());
    }
```

## Contributing to the Pool

```rust
    pub fn contribute(env: Env, member: Address, amount: i128) {
        member.require_auth();
        assert!(amount > 0, "amount must be positive");

        let members: Vec<Address> = env.storage().instance().get(&DataKey::Members).unwrap();
        assert!(members.contains(&member), "not a member");

        let token: Address = env.storage().instance().get(&DataKey::Token).unwrap();
        token::Client::new(&env, &token).transfer(
            &member,
            &env.current_contract_address(),
            &amount,
        );

        let prev: i128 = env.storage().instance()
            .get(&DataKey::Balance(member.clone()))
            .unwrap_or(0);
        env.storage().instance().set(&DataKey::Balance(member.clone()), &(prev + amount));

        let pool: i128 = env.storage().instance().get(&DataKey::TotalPool).unwrap();
        env.storage().instance().set(&DataKey::TotalPool, &(pool + amount));

        env.events().publish((Symbol::new(&env, "contributed"), member), amount);
    }
```

## Withdrawals

Members can withdraw up to their own contributed balance. Larger withdrawals (e.g. from the shared surplus) require admin approval.

```rust
    pub fn withdraw(env: Env, member: Address, amount: i128) {
        member.require_auth();
        assert!(amount > 0, "amount must be positive");

        let balance: i128 = env.storage().instance()
            .get(&DataKey::Balance(member.clone()))
            .unwrap_or(0);
        assert!(balance >= amount, "insufficient personal balance");

        let members: Vec<Address> = env.storage().instance().get(&DataKey::Members).unwrap();
        assert!(members.contains(&member), "not a member");

        env.storage().instance().set(&DataKey::Balance(member.clone()), &(balance - amount));

        let pool: i128 = env.storage().instance().get(&DataKey::TotalPool).unwrap();
        env.storage().instance().set(&DataKey::TotalPool, &(pool - amount));

        let token: Address = env.storage().instance().get(&DataKey::Token).unwrap();
        token::Client::new(&env, &token).transfer(
            &env.current_contract_address(),
            &member,
            &amount,
        );

        env.events().publish((Symbol::new(&env, "withdrawn"), member), amount);
    }

    // Admin-approved withdrawal from pool surplus (e.g. interest or shared fund)
    pub fn admin_distribute(env: Env, admin: Address, recipient: Address, amount: i128) {
        admin.require_auth();
        let stored_admin: Address = env.storage().instance().get(&DataKey::Admin).unwrap();
        assert!(admin == stored_admin, "not admin");

        let pool: i128 = env.storage().instance().get(&DataKey::TotalPool).unwrap();
        assert!(pool >= amount, "insufficient pool balance");

        env.storage().instance().set(&DataKey::TotalPool, &(pool - amount));

        let token: Address = env.storage().instance().get(&DataKey::Token).unwrap();
        token::Client::new(&env, &token).transfer(
            &env.current_contract_address(),
            &recipient,
            &amount,
        );

        env.events().publish((Symbol::new(&env, "distributed"), recipient), amount);
    }
}
```

## Group Governance Notes

| Decision | Who decides | How |
|----------|-------------|-----|
| Add a member | Admin | `add_member` |
| Remove a member | Admin | `remove_member` (balance must be zero) |
| Distribute shared surplus | Admin | `admin_distribute` |
| Upgrade admin | Current admin | `set_admin` (add this function) |
| Emergency exit | Any member | `withdraw` up to own balance at any time |

For a fully decentralized club, replace the admin with a DAO voting contract (see the DAO tutorial) that calls `add_member` and `admin_distribute` only after a quorum vote.

---

## Accuracy Notes

- Each member can only withdraw up to their personally contributed balance; shared surplus is admin-controlled.
- Removing a member requires their balance to be zero first to avoid locking funds.
- Use `env.storage().persistent()` for member balances in long-running savings groups.
- The `Vec<Address>` membership list is scanned linearly; for groups larger than ~50 members, use a `Map<Address, bool>` for O(1) membership checks.
