# Bill Splitter dApp Tutorial

A bill splitter lets a group of people pool payments toward a shared expense. This tutorial builds a Soroban contract where one person creates a bill, others contribute their share, and the contract pays the recipient once the full amount is covered.

---

## Flow Overview

```
Creator                 Contract              Contributors
  |                       |                       |
  |-- create_bill() ----->|                       |
  |                       |<-- contribute() ------|  (each person)
  |                       |   (partial amounts)   |
  |                       |-- payout() ---------->|  (recipient)
  |                       |   (when fully funded) |
```

---

## Data Model

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, token, Address, Env, String, Symbol};

#[contracttype]
pub enum DataKey {
    NextId,
    Bill(u64),
    Contribution(u64, Address),
}

#[contracttype]
#[derive(Clone)]
pub struct Bill {
    pub id:          u64,
    pub creator:     Address,
    pub recipient:   Address,
    pub token:       Address,
    pub total:       i128,
    pub raised:      i128,
    pub description: String,
    pub paid_out:    bool,
}
```

## Creating a Bill

```rust
#[contract]
pub struct BillSplitter;

#[contractimpl]
impl BillSplitter {
    pub fn create_bill(
        env: Env,
        creator: Address,
        recipient: Address,
        token: Address,
        total: i128,
        description: String,
    ) -> u64 {
        creator.require_auth();
        assert!(total > 0, "total must be positive");
        assert!(creator != recipient || true, "creator can be recipient"); // allowed

        let id: u64 = env.storage().instance().get(&DataKey::NextId).unwrap_or(0);
        let bill = Bill {
            id,
            creator,
            recipient,
            token,
            total,
            raised: 0,
            description,
            paid_out: false,
        };
        env.storage().instance().set(&DataKey::Bill(id), &bill);
        env.storage().instance().set(&DataKey::NextId, &(id + 1));

        env.events().publish((Symbol::new(&env, "created"), id), total);
        id
    }
```

## Contributing a Share

```rust
    pub fn contribute(env: Env, contributor: Address, bill_id: u64, amount: i128) {
        contributor.require_auth();
        assert!(amount > 0, "amount must be positive");

        let mut bill: Bill = env.storage().instance()
            .get(&DataKey::Bill(bill_id))
            .expect("bill not found");

        assert!(!bill.paid_out, "bill already paid out");
        assert!(bill.raised < bill.total, "bill already fully funded");
        assert!(
            bill.raised + amount <= bill.total,
            "contribution exceeds remaining balance"
        );

        token::Client::new(&env, &bill.token).transfer(
            &contributor,
            &env.current_contract_address(),
            &amount,
        );

        let prev: i128 = env.storage().instance()
            .get(&DataKey::Contribution(bill_id, contributor.clone()))
            .unwrap_or(0);
        env.storage().instance().set(
            &DataKey::Contribution(bill_id, contributor.clone()),
            &(prev + amount),
        );

        bill.raised += amount;
        env.storage().instance().set(&DataKey::Bill(bill_id), &bill);

        env.events().publish(
            (Symbol::new(&env, "contributed"), bill_id, contributor),
            amount,
        );

        // Auto-payout when fully funded
        if bill.raised == bill.total {
            Self::_payout(&env, &mut bill, bill_id);
        }
    }
```

## Payout

```rust
    fn _payout(env: &Env, bill: &mut Bill, bill_id: u64) {
        token::Client::new(env, &bill.token).transfer(
            &env.current_contract_address(),
            &bill.recipient,
            &bill.raised,
        );
        bill.paid_out = true;
        env.storage().instance().set(&DataKey::Bill(bill_id), bill);
        env.events().publish((Symbol::new(env, "paid_out"), bill_id), bill.raised);
    }

    // Manual payout trigger (if auto-payout fails or is skipped)
    pub fn payout(env: Env, caller: Address, bill_id: u64) {
        caller.require_auth();
        let mut bill: Bill = env.storage().instance()
            .get(&DataKey::Bill(bill_id))
            .expect("bill not found");

        assert!(!bill.paid_out, "already paid out");
        assert!(bill.raised >= bill.total, "not fully funded yet");
        assert!(
            caller == bill.creator || caller == bill.recipient,
            "only creator or recipient can trigger payout"
        );

        Self::_payout(&env, &mut bill, bill_id);
    }
}
```

## Edge Cases

| Scenario | Handling |
|----------|---------|
| Contributor sends too much | Assertion `raised + amount <= total` rejects the excess; contributor adjusts amount |
| Bill never fully funded | Creator can add a `cancel` function to return contributions individually |
| Recipient is also a contributor | Allowed — they can pay their own share |
| Multiple currencies | Deploy one bill contract per token; pass different `token` addresses |
| Contributor wants to back out | Add an `opt_out` function that returns their contribution and reduces `raised` |

## Accuracy Notes

- `bill.raised + amount <= bill.total` prevents overfunding; the contributor must call with the exact remaining amount if joining last.
- Use `env.storage().persistent()` for bills that may remain open for more than ~100 ledgers.
- The auto-payout inside `contribute` keeps the flow atomic — no separate payout transaction needed in the happy path.
