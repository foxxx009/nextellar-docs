# Crowdfunding Contract Tutorial

This tutorial builds a Soroban crowdfunding contract where contributors send tokens toward a campaign goal. If the goal is reached before the deadline the owner can withdraw funds; if it is not, contributors can reclaim their individual deposits.

---

## Contract Design

| State | Description |
|-------|-------------|
| `Open` | Contributions accepted, goal not yet reached, deadline not passed |
| `Successful` | Goal reached before deadline; owner may withdraw |
| `Failed` | Deadline passed without reaching goal; contributors may refund |

---

## Data Model

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, token, Address, Env, Symbol};

#[contracttype]
pub enum DataKey {
    Owner,
    Goal,
    Deadline,
    Token,
    Raised,
    Contribution(Address),
}
```

---

## Initialization

```rust
#[contract]
pub struct Crowdfund;

#[contractimpl]
impl Crowdfund {
    pub fn initialize(
        env: Env,
        owner: Address,
        token: Address,
        goal: i128,
        deadline: u64, // Unix timestamp (seconds)
    ) {
        assert!(
            !env.storage().instance().has(&DataKey::Owner),
            "already initialized"
        );
        assert!(goal > 0, "goal must be positive");
        assert!(
            deadline > env.ledger().timestamp(),
            "deadline must be in the future"
        );

        env.storage().instance().set(&DataKey::Owner,    &owner);
        env.storage().instance().set(&DataKey::Token,    &token);
        env.storage().instance().set(&DataKey::Goal,     &goal);
        env.storage().instance().set(&DataKey::Deadline, &deadline);
        env.storage().instance().set(&DataKey::Raised,   &0_i128);
    }
```

## Contributing

```rust
    pub fn contribute(env: Env, contributor: Address, amount: i128) {
        contributor.require_auth();
        assert!(amount > 0, "amount must be positive");
        assert!(
            env.ledger().timestamp() < env.storage().instance().get::<_, u64>(&DataKey::Deadline).unwrap(),
            "campaign closed"
        );

        let token: Address = env.storage().instance().get(&DataKey::Token).unwrap();
        token::Client::new(&env, &token).transfer(&contributor, &env.current_contract_address(), &amount);

        let prev: i128 = env.storage().instance()
            .get(&DataKey::Contribution(contributor.clone()))
            .unwrap_or(0);
        env.storage().instance().set(&DataKey::Contribution(contributor.clone()), &(prev + amount));

        let raised: i128 = env.storage().instance().get(&DataKey::Raised).unwrap();
        env.storage().instance().set(&DataKey::Raised, &(raised + amount));

        env.events().publish(
            (Symbol::new(&env, "contribute"), contributor),
            amount,
        );
    }
```

## Withdrawal (Successful Campaign)

```rust
    pub fn withdraw(env: Env) {
        let owner: Address = env.storage().instance().get(&DataKey::Owner).unwrap();
        owner.require_auth();

        let raised:    i128 = env.storage().instance().get(&DataKey::Raised).unwrap();
        let goal:      i128 = env.storage().instance().get(&DataKey::Goal).unwrap();
        let deadline:  u64  = env.storage().instance().get(&DataKey::Deadline).unwrap();

        assert!(raised >= goal,                          "goal not reached");
        assert!(env.ledger().timestamp() >= deadline ||
                raised >= goal,                          "campaign still open");

        let token: Address = env.storage().instance().get(&DataKey::Token).unwrap();
        token::Client::new(&env, &token).transfer(&env.current_contract_address(), &owner, &raised);

        env.storage().instance().set(&DataKey::Raised, &0_i128);

        env.events().publish((Symbol::new(&env, "withdraw"), owner), raised);
    }
```

---

## Refund (Failed Campaign)

```rust
    pub fn refund(env: Env, contributor: Address) {
        contributor.require_auth();

        let deadline: u64  = env.storage().instance().get(&DataKey::Deadline).unwrap();
        let raised:   i128 = env.storage().instance().get(&DataKey::Raised).unwrap();
        let goal:     i128 = env.storage().instance().get(&DataKey::Goal).unwrap();

        assert!(
            env.ledger().timestamp() >= deadline && raised < goal,
            "refunds not available yet"
        );

        let amount: i128 = env.storage().instance()
            .get(&DataKey::Contribution(contributor.clone()))
            .unwrap_or(0);
        assert!(amount > 0, "no contribution to refund");

        env.storage().instance().set(&DataKey::Contribution(contributor.clone()), &0_i128);

        let token: Address = env.storage().instance().get(&DataKey::Token).unwrap();
        token::Client::new(&env, &token).transfer(&env.current_contract_address(), &contributor, &amount);

        env.events().publish((Symbol::new(&env, "refund"), contributor), amount);
    }
}
```

## Off-Chain Interaction

```ts
import { Contract, SorobanRpc, TransactionBuilder, Networks, BASE_FEE } from "@stellar/stellar-sdk";

const server   = new SorobanRpc.Server("https://soroban-testnet.stellar.org");
const CONTRACT = "C..."; // deployed contract ID

async function contribute(contributorKeypair: Keypair, amount: bigint) {
  const account  = await server.getAccount(contributorKeypair.publicKey());
  const contract = new Contract(CONTRACT);

  const tx = new TransactionBuilder(account, { fee: BASE_FEE, networkPassphrase: Networks.TESTNET })
    .addOperation(contract.call("contribute", /* contributor Address xdr, amount i128 xdr */))
    .setTimeout(30)
    .build();

  const prepared = await server.prepareTransaction(tx);
  prepared.sign(contributorKeypair);
  return server.sendTransaction(prepared);
}
```

## State Diagram

```
         initialize()
              │
              ▼
           [Open]
         contribute()
              │
    ┌─────────┴──────────┐
    │ deadline passed     │ goal reached
    │ goal NOT reached    │ (at any time)
    ▼                     ▼
 [Failed]           [Successful]
 refund()            withdraw()
```

## Accuracy Notes

- `env.ledger().timestamp()` is set by validators and advances with each ledger close (~5 seconds); it is reliable for deadline checks.
- Use a SAC (Stellar Asset Contract) token address for the `token` parameter to accept XLM or any Stellar classic asset.
- Extend instance storage TTL with `env.storage().instance().extend_ttl(...)` if the campaign runs longer than the default ~100-ledger window.
- In production, add a `cancel` function callable by the owner before the deadline to trigger early refunds.
