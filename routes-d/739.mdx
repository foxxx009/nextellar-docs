# Real Estate Tokenization App

This tutorial walks through issuing and transferring real-world assets on Stellar.

## Asset Issuance
On Stellar, any real estate property can be tokenized by an issuer via the Asset Issuance standard.

## Working Example
```typescript
import { Asset, Server, TransactionBuilder } from 'stellar-sdk';
// Issue REAL_ESTATE_TOKEN
```

## Compliance Touchpoints
Before assets are transferred, proper KYC/AML is validated via authorized trustlines and clawback functionalities.
