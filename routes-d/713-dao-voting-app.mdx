# DAO Voting App Tutorial

This tutorial builds a Soroban DAO voting contract where governance token holders create proposals, cast weighted votes, and execute approved actions on-chain. It covers the full lifecycle: proposal creation → voting → quorum check → execution or rejection.

---

## Contract Overview

| Feature | Implementation |
|---------|---------------|
| Proposals | Stored by ID with description, vote tallies, and deadline |
| Vote weight | Proportional to caller's governance token balance |
| Quorum | Minimum total votes needed for a proposal to pass |
| Execution | Owner-callable after quorum + majority confirmed |
| Vote change | Not allowed after casting (immutable ballot) |

## Data Model

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, token, Address, Env, String, Symbol};

#[contracttype]
pub enum DataKey {
    NextId,
    Proposal(u64),
    Vote(u64, Address), // proposal_id, voter → vote cast
    GovToken,
    Quorum,
    Owner,
}

#[contracttype]
#[derive(Clone)]
pub struct Proposal {
    pub id:          u64,
    pub description: String,
    pub yes_votes:   i128,
    pub no_votes:    i128,
    pub deadline:    u64,  // ledger timestamp
    pub executed:    bool,
    pub passed:      bool,
}
```

## Initialization

```rust
#[contract]
pub struct Dao;

#[contractimpl]
impl Dao {
    pub fn initialize(
        env: Env,
        owner: Address,
        gov_token: Address,
        quorum: i128, // minimum total votes (in token units) for a proposal to be valid
    ) {
        assert!(!env.storage().instance().has(&DataKey::Owner), "already initialized");
        env.storage().instance().set(&DataKey::Owner,    &owner);
        env.storage().instance().set(&DataKey::GovToken, &gov_token);
        env.storage().instance().set(&DataKey::Quorum,   &quorum);
        env.storage().instance().set(&DataKey::NextId,   &0_u64);
    }
```

## Creating a Proposal

```rust
    pub fn propose(env: Env, proposer: Address, description: String, voting_period: u64) -> u64 {
        proposer.require_auth();

        let id: u64 = env.storage().instance().get(&DataKey::NextId).unwrap_or(0);
        let proposal = Proposal {
            id,
            description,
            yes_votes: 0,
            no_votes:  0,
            deadline:  env.ledger().timestamp() + voting_period,
            executed:  false,
            passed:    false,
        };
        env.storage().instance().set(&DataKey::Proposal(id), &proposal);
        env.storage().instance().set(&DataKey::NextId, &(id + 1));

        env.events().publish((Symbol::new(&env, "propose"), id), proposer);
        id
    }
```

## Casting a Vote

```rust
    pub fn vote(env: Env, voter: Address, proposal_id: u64, support: bool) {
        voter.require_auth();

        assert!(
            !env.storage().instance().has(&DataKey::Vote(proposal_id, voter.clone())),
            "already voted"
        );

        let mut proposal: Proposal = env.storage().instance()
            .get(&DataKey::Proposal(proposal_id))
            .expect("proposal not found");

        assert!(!proposal.executed,                                    "proposal already executed");
        assert!(env.ledger().timestamp() < proposal.deadline,          "voting period closed");

        // Weight vote by caller's governance token balance
        let gov_token: Address = env.storage().instance().get(&DataKey::GovToken).unwrap();
        let weight = token::Client::new(&env, &gov_token).balance(&voter);
        assert!(weight > 0, "no governance tokens");

        if support {
            proposal.yes_votes += weight;
        } else {
            proposal.no_votes += weight;
        }

        env.storage().instance().set(&DataKey::Proposal(proposal_id), &proposal);
        env.storage().instance().set(&DataKey::Vote(proposal_id, voter.clone()), &support);

        env.events().publish(
            (Symbol::new(&env, "vote"), proposal_id, voter),
            (support, weight),
        );
    }
```

## Finalizing and Executing

```rust
    pub fn execute(env: Env, caller: Address, proposal_id: u64) {
        caller.require_auth();

        let owner: Address = env.storage().instance().get(&DataKey::Owner).unwrap();
        assert!(caller == owner, "only owner can execute");

        let mut proposal: Proposal = env.storage().instance()
            .get(&DataKey::Proposal(proposal_id))
            .expect("proposal not found");

        assert!(!proposal.executed,                           "already executed");
        assert!(env.ledger().timestamp() >= proposal.deadline, "voting still open");

        let quorum: i128 = env.storage().instance().get(&DataKey::Quorum).unwrap();
        let total = proposal.yes_votes + proposal.no_votes;

        proposal.passed   = total >= quorum && proposal.yes_votes > proposal.no_votes;
        proposal.executed = true;
        env.storage().instance().set(&DataKey::Proposal(proposal_id), &proposal);

        env.events().publish(
            (Symbol::new(&env, "execute"), proposal_id),
            proposal.passed,
        );

        // Add custom on-chain actions here when passed == true
        // e.g., transfer treasury funds, update a config key, etc.
    }
}
```

## Off-Chain Integration

```ts
import { Contract, SorobanRpc, TransactionBuilder, Networks, BASE_FEE, xdr } from "@stellar/stellar-sdk";

const server   = new SorobanRpc.Server("https://soroban-testnet.stellar.org");
const CONTRACT = "C...";

async function castVote(voterKeypair: Keypair, proposalId: bigint, support: boolean) {
  const account  = await server.getAccount(voterKeypair.publicKey());
  const contract = new Contract(CONTRACT);

  const tx = new TransactionBuilder(account, { fee: BASE_FEE, networkPassphrase: Networks.TESTNET })
    .addOperation(
      contract.call(
        "vote",
        // voter Address, proposal_id u64, support bool — encode as XDR args
      )
    )
    .setTimeout(30)
    .build();

  const prepared = await server.prepareTransaction(tx);
  prepared.sign(voterKeypair);
  return server.sendTransaction(prepared);
}
```

## Proposal Lifecycle

```
propose()          vote() (multiple callers)          execute()
    │                        │                            │
    ▼                        ▼                            ▼
[Created]  ──────────→  [Voting Open]  ──────────→  [Closed]
                                                          │
                                           ┌──────────────┴──────────────┐
                                           │ quorum met + yes > no        │ quorum not met or no wins
                                           ▼                              ▼
                                       [Passed]                      [Rejected]
                                    (on-chain action)
```

## Governance Design Notes

- **Token snapshot vs live balance**: this implementation uses the live balance at vote time. For resistance to vote buying, consider snapshotting balances at proposal creation using a separate checkpoint mapping.
- **Delegation**: not implemented here; add a `delegate(voter, delegatee)` function that routes voting weight from one address to another.
- **Timelock**: for safety, add a delay between `execute` being called and the on-chain action firing, giving token holders a window to exit if they disagree.
- **Quorum calibration**: set quorum to at least 10–20 % of total token supply so small groups cannot pass proposals unilaterally.
