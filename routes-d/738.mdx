# Key Ceremony Procedures

This guide provides a thorough key ceremony procedure for Stellar asset issuers.

## Roles and Steps
- **Master of Ceremony**: Orchestrates the event.
- **Key Custodians**: Multi-sig holders who secure individual shares.

## Verification Checkpoints
Every hardware wallet must be verified for tamper evidence before initialization.

## Checklist
- [ ] Air-gapped machine prepped
- [ ] Wallet initialization
- [ ] Multi-sig configuration applied
- [ ] Backup shards generated and secured
