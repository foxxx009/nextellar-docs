# Full Reference for Every CLI Flag with Stellar Examples

The Stellar CLI (`stellar`) is the primary command-line tool for interacting with the Stellar Network and deploying Soroban smart contracts. This reference covers all major CLI flags, their default values, and concrete examples for real-world development workflows.

---

## Global & Network Flags

### `--network`

Specifies the target Stellar network environment.

- **Type**: String
- **Default**: `testnet`
- **Supported Values**: `mainnet`, `testnet`, `futurenet`, `local`
- **Example**:
  ```bash
  stellar keys generate my-account --network mainnet
  ```

### `--rpc-url`

Overrides the default JSON-RPC endpoint for Soroban RPC operations.

- **Type**: URL String
- **Default**: Auto-configured based on `--network` (e.g., `https://soroban-testnet.stellar.org:443`)
- **Example**:
  ```bash
  stellar contract deploy --wasm build/contract.wasm --rpc-url https://custom-rpc.example.com --network testnet
  ```

### `--network-passphrase`

Explicitly provides the Stellar network passphrase instead of relying on preset network profiles.

- **Type**: String
- **Default**: Inferred from `--network` (e.g., `"Test SDF Network ; July 2015"`)
- **Example**:
  ```bash
  stellar tx Send --network-passphrase "Standalone Network ; February 2022" --rpc-url http://localhost:8000/soroban/rpc
  ```

## Identity & Signing Flags

### `--source` / `--source-account`

Specifies the identity or secret key executing the transaction.

- **Type**: Name or Stellar Secret Key (`S...`)
- **Default**: Default configured key identity
- **Example**:
  ```bash
  stellar contract invoke --id CC... --source alice --fn initialize
  ```

### `--hd-path`

Defines the BIP-44 derivation path when generating or restoring accounts from seed phrases.

- **Type**: String
- **Default**: `m/44'/148'/0'`
- **Example**:
  ```bash
  stellar keys add my-hw-key --hd-path "m/44'/148'/1'"
  ```

## Transaction & Fee Control Flags

### `--fee`

Sets the maximum fee willing to be paid for transaction inclusion in Stroops (1 XLM = 10,000,000 Stroops).

- **Type**: Integer
- **Default**: `100` Stroops (base fee)
- **Example**:
  ```bash
  stellar tx new payment --destination G... --amount 500 --fee 1000 --source alice
  ```

### `--timeout`

Sets the maximum time in seconds for transaction execution before timing out.

- **Type**: Integer
- **Default**: `30` seconds
- **Example**:
  ```bash
  stellar tx Send --timeout 60 --source alice
  ```

### `--slop`

Specifies resource padding for Soroban resource estimation (CPU, memory, instructions) to prevent inclusion failures under high congestion.

- **Type**: Percentage or integer buffer
- **Default**: `20%`
- **Example**:
  ```bash
  stellar contract invoke --id CC... --slop 30 --source dev-key
  ```

## Contract Build & Output Flags

### `--wasm`

Path to compiled WebAssembly binary file for smart contract operations.

- **Type**: File Path
- **Default**: None (Required for contract deployment/installation)
- **Example**:
  ```bash
  stellar contract install --wasm target/wasm32-unknown-unknown/release/vault.wasm --source deployer
  ```

### `--out-dir`

Specifies destination directory when generating TypeScript SDK client bindings or contract artifacts.

- **Type**: Directory Path
- **Default**: `./`
- **Example**:
  ```bash
  stellar contract bindings typescript --wasm target/wasm32-unknown-unknown/release/vault.wasm --out-dir ./src/contracts/vault
  ```

### `--json`

Outputs command responses as structured JSON for automation and scripting integration.

- **Type**: Boolean Flag
- **Default**: `false` (human-readable tabular output)
- **Example**:
  ```bash
  stellar keys address alice --json
  ```
