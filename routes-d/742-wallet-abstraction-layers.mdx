# Wallet Abstraction Layers

Stellar dApps must support multiple wallet providers: browser extensions (Freighter), mobile wallets (LOBSTR), hardware signers, and raw keypairs for testing. A wallet abstraction layer defines a single interface your application code talks to, hiding provider-specific details behind a stable API.

---

## Common Abstraction Points

Every Stellar wallet interaction reduces to three operations:

| Operation | Description |
|-----------|-------------|
| `getPublicKey()` | Return the active account's public key |
| `signTransaction(xdr)` | Sign a transaction XDR and return the signed XDR |
| `signAuthEntry(entry)` | Sign a Soroban auth entry for contract invocations |

Any provider that implements these three methods is a valid wallet in your abstraction.

---

## Interface Definition

```ts
export interface StellarWallet {
  getPublicKey(): Promise<string>;
  signTransaction(xdr: string, opts?: { networkPassphrase?: string }): Promise<string>;
  signAuthEntry(entryXdr: string): Promise<string>;
}
```

## Freighter Adapter

```ts
import {
  getPublicKey,
  signTransaction,
  signAuthEntry,
  isConnected,
} from "@stellar/freighter-api";

export class FreighterWallet implements StellarWallet {
  async getPublicKey(): Promise<string> {
    const connected = await isConnected();
    if (!connected.isConnected) throw new Error("Freighter not connected");
    const result = await getPublicKey();
    if (result.error) throw new Error(result.error);
    return result.publicKey;
  }

  async signTransaction(xdr: string, opts?: { networkPassphrase?: string }): Promise<string> {
    const result = await signTransaction(xdr, {
      networkPassphrase: opts?.networkPassphrase,
    });
    if (result.error) throw new Error(result.error);
    return result.signedTxXdr;
  }

  async signAuthEntry(entryXdr: string): Promise<string> {
    const result = await signAuthEntry(entryXdr);
    if (result.error) throw new Error(result.error);
    return result.signedAuthEntry;
  }
}
```

## Keypair Adapter (Testing / Server-Side)

```ts
import { Keypair, Transaction, xdr, Networks } from "@stellar/stellar-sdk";

export class KeypairWallet implements StellarWallet {
  constructor(private readonly keypair: Keypair) {}

  async getPublicKey(): Promise<string> {
    return this.keypair.publicKey();
  }

  async signTransaction(txXdr: string, opts?: { networkPassphrase?: string }): Promise<string> {
    const network = opts?.networkPassphrase ?? Networks.TESTNET;
    const tx      = new Transaction(txXdr, network);
    tx.sign(this.keypair);
    return tx.toXDR();
  }

  async signAuthEntry(entryXdr: string): Promise<string> {
    const entry     = xdr.SorobanAuthorizationEntry.fromXDR(entryXdr, "base64");
    const signature = this.keypair.sign(entry.toXDR());
    return signature.toString("base64");
  }
}
```

## WalletConnect Adapter (Skeleton)

```ts
import WalletConnect from "@walletconnect/sign-client";

export class WalletConnectWallet implements StellarWallet {
  private client: WalletConnect | null = null;
  private session: any                 = null;

  async connect(projectId: string) {
    this.client = await WalletConnect.init({ projectId });
    // Pair and establish session — see WalletConnect docs for full pairing flow
  }

  async getPublicKey(): Promise<string> {
    // Extract from session namespace
    const accounts = this.session.namespaces["stellar"].accounts;
    return accounts[0].split(":")[2]; // "stellar:testnet:GPUBKEY"
  }

  async signTransaction(xdr: string): Promise<string> {
    const result = await this.client!.request({
      topic:   this.session.topic,
      chainId: "stellar:testnet",
      request: { method: "stellar_signTransaction", params: { xdr } },
    });
    return result.signedXdr;
  }

  async signAuthEntry(entryXdr: string): Promise<string> {
    const result = await this.client!.request({
      topic:   this.session.topic,
      chainId: "stellar:testnet",
      request: { method: "stellar_signAuthEntry", params: { entryXdr } },
    });
    return result.signedEntry;
  }
}
```

## Factory and Usage

```ts
type WalletType = "freighter" | "keypair" | "walletconnect";

function createWallet(type: WalletType, opts?: { secret?: string }): StellarWallet {
  switch (type) {
    case "freighter":     return new FreighterWallet();
    case "keypair":       return new KeypairWallet(Keypair.fromSecret(opts!.secret!));
    case "walletconnect": return new WalletConnectWallet();
  }
}

// Application code never imports a specific wallet — only the interface
async function sendPayment(wallet: StellarWallet, destination: string, amount: string) {
  const publicKey = await wallet.getPublicKey();
  const account   = await server.loadAccount(publicKey);
  const tx = new TransactionBuilder(account, { fee: BASE_FEE, networkPassphrase: Networks.TESTNET })
    .addOperation(Operation.payment({ destination, asset: Asset.native(), amount }))
    .setTimeout(30)
    .build();

  const signedXdr = await wallet.signTransaction(tx.toXDR(), { networkPassphrase: Networks.TESTNET });
  return server.submitTransaction(new Transaction(signedXdr, Networks.TESTNET));
}
```

## Interface Comparison

| Provider | `getPublicKey` | `signTransaction` | `signAuthEntry` | Environment |
|----------|---------------|-------------------|-----------------|-------------|
| Freighter | Extension API | Extension API | Extension API | Browser only |
| Keypair | Synchronous | Local | Local | Any |
| WalletConnect | Session namespace | JSON-RPC | JSON-RPC | Browser + mobile |
| LOBSTR | Via SEP-7 URI | Deep link | Not supported | Mobile |

---

## Accuracy Notes

- Freighter's API surface changes between major versions; pin `@stellar/freighter-api` and check the changelog on upgrades.
- `signAuthEntry` is only needed for Soroban contract invocations that require caller authorization; standard payment transactions only need `signTransaction`.
- WalletConnect Stellar support depends on the wallet's implementation of the `stellar_*` JSON-RPC methods; verify support before shipping.
