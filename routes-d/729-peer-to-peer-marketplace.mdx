# Peer-to-Peer Marketplace Tutorial

This tutorial builds a small P2P marketplace on Soroban: sellers create listings, buyers deposit funds into escrow, and the contract releases payment on delivery confirmation. It also covers the dispute path when buyer and seller disagree.

---

## Contract Design

```
Seller              Contract (escrow)           Buyer
  |                       |                       |
  |-- create_listing() -->|                       |
  |                       |<-- deposit() ---------|
  |                       |   (funds locked)      |
  |-- (ship item) ------->|                       |
  |                       |<-- confirm() ---------|
  |                       |   (or dispute())      |
  |<-- release() ---------|                       |
  |   (funds to seller)   |                       |
```

---

## Data Model

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, token, Address, Env, String, Symbol};

#[contracttype]
pub enum DataKey {
    NextId,
    Listing(u64),
    Admin,
}

#[contracttype]
#[derive(Clone)]
pub enum ListingStatus {
    Open,
    Funded,
    Completed,
    Disputed,
    Cancelled,
}

#[contracttype]
#[derive(Clone)]
pub struct Listing {
    pub id:          u64,
    pub seller:      Address,
    pub buyer:       Option<Address>,
    pub token:       Address,
    pub price:       i128,
    pub description: String,
    pub status:      ListingStatus,
}
```

## Creating a Listing

```rust
#[contract]
pub struct Marketplace;

#[contractimpl]
impl Marketplace {
    pub fn initialize(env: Env, admin: Address) {
        assert!(!env.storage().instance().has(&DataKey::Admin), "already initialized");
        env.storage().instance().set(&DataKey::Admin, &admin);
        env.storage().instance().set(&DataKey::NextId, &0_u64);
    }

    pub fn create_listing(
        env: Env,
        seller: Address,
        token: Address,
        price: i128,
        description: String,
    ) -> u64 {
        seller.require_auth();
        assert!(price > 0, "price must be positive");

        let id: u64 = env.storage().instance().get(&DataKey::NextId).unwrap_or(0);
        let listing = Listing {
            id,
            seller,
            buyer: None,
            token,
            price,
            description,
            status: ListingStatus::Open,
        };
        env.storage().instance().set(&DataKey::Listing(id), &listing);
        env.storage().instance().set(&DataKey::NextId, &(id + 1));

        env.events().publish((Symbol::new(&env, "listed"), id), listing.price);
        id
    }
```

## Deposit into Escrow

```rust
    pub fn deposit(env: Env, buyer: Address, listing_id: u64) {
        buyer.require_auth();

        let mut listing: Listing = env.storage().instance()
            .get(&DataKey::Listing(listing_id))
            .expect("listing not found");

        assert!(matches!(listing.status, ListingStatus::Open), "listing not open");
        assert!(listing.seller != buyer, "seller cannot buy own listing");

        token::Client::new(&env, &listing.token).transfer(
            &buyer,
            &env.current_contract_address(),
            &listing.price,
        );

        listing.buyer  = Some(buyer);
        listing.status = ListingStatus::Funded;
        env.storage().instance().set(&DataKey::Listing(listing_id), &listing);

        env.events().publish((Symbol::new(&env, "funded"), listing_id), listing.price);
    }
```

## Confirm and Release

```rust
    pub fn confirm(env: Env, caller: Address, listing_id: u64) {
        caller.require_auth();

        let mut listing: Listing = env.storage().instance()
            .get(&DataKey::Listing(listing_id))
            .expect("listing not found");

        assert!(matches!(listing.status, ListingStatus::Funded), "not in funded state");
        let buyer = listing.buyer.clone().expect("no buyer");
        assert!(caller == buyer, "only buyer can confirm");

        token::Client::new(&env, &listing.token).transfer(
            &env.current_contract_address(),
            &listing.seller,
            &listing.price,
        );

        listing.status = ListingStatus::Completed;
        env.storage().instance().set(&DataKey::Listing(listing_id), &listing);

        env.events().publish((Symbol::new(&env, "completed"), listing_id), listing.price);
    }
```

## Dispute Resolution

```rust
    pub fn dispute(env: Env, caller: Address, listing_id: u64) {
        caller.require_auth();

        let mut listing: Listing = env.storage().instance()
            .get(&DataKey::Listing(listing_id))
            .expect("listing not found");

        assert!(matches!(listing.status, ListingStatus::Funded), "not in funded state");
        let buyer = listing.buyer.clone().expect("no buyer");
        assert!(caller == buyer || caller == listing.seller, "not a party");

        listing.status = ListingStatus::Disputed;
        env.storage().instance().set(&DataKey::Listing(listing_id), &listing);

        env.events().publish((Symbol::new(&env, "disputed"), listing_id), caller);
    }

    // Admin resolves: winner receives escrowed funds
    pub fn resolve(env: Env, admin: Address, listing_id: u64, release_to_seller: bool) {
        admin.require_auth();
        let stored_admin: Address = env.storage().instance().get(&DataKey::Admin).unwrap();
        assert!(admin == stored_admin, "not admin");

        let mut listing: Listing = env.storage().instance()
            .get(&DataKey::Listing(listing_id))
            .expect("listing not found");

        assert!(matches!(listing.status, ListingStatus::Disputed), "not disputed");

        let recipient = if release_to_seller {
            listing.seller.clone()
        } else {
            listing.buyer.clone().expect("no buyer")
        };

        token::Client::new(&env, &listing.token).transfer(
            &env.current_contract_address(),
            &recipient,
            &listing.price,
        );

        listing.status = ListingStatus::Completed;
        env.storage().instance().set(&DataKey::Listing(listing_id), &listing);

        env.events().publish((Symbol::new(&env, "resolved"), listing_id), recipient);
    }
}
```

---

## Dispute Paths

| Who raises dispute | Admin decision | Outcome |
|-------------------|---------------|---------|
| Buyer (item not received) | `release_to_seller = false` | Buyer refunded |
| Seller (buyer non-responsive) | `release_to_seller = true` | Seller paid |
| Either party | Evidence reviewed off-chain | Admin sets winner |

---

## Accuracy Notes

- The admin account should be a multi-sig or a DAO contract to avoid a single point of trust in disputes.
- Add a `cancel` function for the seller to reclaim a listing that has no buyer yet.
- Use `env.storage().persistent()` for listings expected to persist beyond the default instance TTL.
- In production, integrate with a reputation system so dispute history is visible before engaging with a counterparty.
