# Removing a Trustline

A trustline locks 0.5 XLM in reserve for as long as it exists — even with a zero balance. Removing a trustline frees that reserve and cleans up your account's entry list. This guide covers the prerequisites, the operation, and the reserve implications.

---

## Prerequisites

Before removing a trustline, two conditions must be true:

1. **Balance must be zero.** You cannot remove a trustline that holds any amount of the asset. Send or sell all holdings first.
2. **No pending offers or claimable balances.** Open offers and unclaimed claimable balances referencing the asset prevent removal. Cancel or claim them first.

If either condition is not met, the network returns `op_low_reserve` or `op_not_supported`.

---

## Step 1: Verify Zero Balance

Check the current balance via Horizon or the `useTrustlines` hook:

```tsx
import { useTrustlines } from '@/hooks/useTrustlines';

function TrustlineStatus({ publicKey }: { publicKey: string }) {
  const { trustlines } = useTrustlines(publicKey);
  const asset = trustlines.find(
    (t) => t.asset_code === 'ACME' && t.asset_issuer === 'GAIZ...'
  );

  if (!asset) return <p>No trustline for ACME</p>;
  if (Number(asset.balance) > 0) {
    return <p>Balance: {asset.balance} — send or sell before removing</p>;
  }
  return <p>Balance is zero — safe to remove</p>;
}
```

If the balance is not zero, transfer or sell all holdings before proceeding.

---

## Step 2: Submit a change-trust Operation

To remove a trustline, submit a `changeTrust` operation with `limit: '0'`:

```ts
import {
  Horizon,
  Keypair,
  Networks,
  TransactionBuilder,
  BASE_FEE,
  Asset,
  Operation,
} from '@stellar/stellar-sdk';

const server = new Horizon.Server(process.env.HORIZON_URL!);
const keypair = Keypair.fromSecret(process.env.SECRET!);

const ACME = new Asset('ACME', 'GAIZ...');

async function removeTrustline() {
  const account = await server.loadAccount(keypair.publicKey());

  const tx = new TransactionBuilder(account, {
    fee: BASE_FEE,
    networkPassphrase: Networks.TESTNET,
  })
    .addOperation(
      Operation.changeTrust({
        asset: ACME,
        limit: '0', // setting limit to 0 removes the trustline
      })
    )
    .setTimeout(30)
    .build();

  tx.sign(keypair);
  const result = await server.submitTransaction(tx);
  console.log('Trustline removed:', result.hash);
}
```

### What `limit: '0'` Does

- If the trustline **does not exist**: the operation is a no-op (succeeds silently).
- If the trustline **exists with zero balance**: the trustline entry is deleted from the ledger.
- If the trustline **exists with a non-zero balance**: the transaction fails with an error.

---

## Step 3: Confirm the Reserve Is Freed

After removal, the 0.5 XLM reserve locked by the trustline returns to your available balance. You can verify this by checking your account's `balances` array — the entry for the removed asset disappears, and `available_balance` increases by 0.5 XLM.

```ts
const account = await server.loadAccount(keypair.publicKey());
const native = account.balances.find((b) => b.asset_type === 'native');
console.log('Available XLM:', native.balance);
```

## Reserve Implications

Every trustline entry on Stellar requires a base reserve of **0.5 XLM**. This reserve is locked — not spent — and is returned when the entry is deleted.

| Entries       | Reserve locked | Notes                    |
| ------------- | -------------- | ------------------------ |
| 1 trustline   | 0.5 XLM        | Freed on removal         |
| 10 trustlines | 5.0 XLM        | Freed as each is removed |
| 0 trustlines  | 0 XLM          | All reserves reclaimed   |

The minimum account balance is calculated as:

```
base_reserve × (1 + number_of_entries)
```

Where the `1` accounts for the account itself. Each trustline, offer, data entry, and signers count as an entry.

## Common Pitfalls

| Pitfall            | Cause                               | Fix                                      |
| ------------------ | ----------------------------------- | ---------------------------------------- |
| `op_low_reserve`   | Balance is not zero                 | Send or sell all holdings first          |
| `op_not_supported` | Open offers reference the asset     | Cancel all offers for the asset          |
| Trustline persists | Balance was non-zero at submit time | Verify balance is `0` in the same ledger |
| Reserve not freed  | Transaction failed silently         | Check transaction result for errors      |
