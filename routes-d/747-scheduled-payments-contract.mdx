# Scheduled Payments Contract Tutorial

Soroban contracts cannot call themselves on a timer — there is no native cron on-chain. This tutorial builds a scheduled payments contract where the schedule is stored on-chain and an off-chain keeper triggers execution when the time arrives.

---

## Architecture

```
Off-chain Keeper                Contract                  Token
      |                            |                        |
      |-- (every ~5 seconds) ----->|                        |
      |   check isDue(schedule_id) |                        |
      |                            |                        |
      |-- execute(schedule_id) --->|                        |
      |                            |-- transfer() --------->|
      |                            |   (to recipient)       |
```

The keeper can be a simple cron job, a serverless function, or a Stellar bot.

---

## Data Model

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, token, Address, Env, Symbol};

#[contracttype]
pub enum DataKey {
    Admin,
    NextId,
    Schedule(u64),
}

#[contracttype]
#[derive(Clone)]
pub struct Schedule {
    pub id:            u64,
    pub owner:         Address,
    pub recipient:     Address,
    pub token:         Address,
    pub amount:        i128,
    pub interval:      u64,   // seconds between payments
    pub next_due:      u64,   // Unix timestamp of next payment
    pub remaining:     u32,   // 0 = unlimited
    pub executed:      u32,   // total times executed
    pub paused:        bool,
}
```

## Initialization

```rust
#[contract]
pub struct ScheduledPayments;

#[contractimpl]
impl ScheduledPayments {
    pub fn initialize(env: Env, admin: Address) {
        assert!(!env.storage().instance().has(&DataKey::Admin), "already initialized");
        env.storage().instance().set(&DataKey::Admin, &admin);
        env.storage().instance().set(&DataKey::NextId, &0_u64);
    }
```

## Creating a Schedule

```rust
    pub fn create_schedule(
        env: Env,
        owner: Address,
        recipient: Address,
        token: Address,
        amount: i128,
        interval: u64,
        remaining: u32, // 0 = run forever
    ) -> u64 {
        owner.require_auth();
        assert!(amount > 0, "amount must be positive");
        assert!(interval >= 60, "interval must be at least 60 seconds");

        let id: u64 = env.storage().instance().get(&DataKey::NextId).unwrap_or(0);
        let schedule = Schedule {
            id,
            owner,
            recipient,
            token,
            amount,
            interval,
            next_due: env.ledger().timestamp() + interval,
            remaining,
            executed: 0,
            paused: false,
        };
        env.storage().instance().set(&DataKey::Schedule(id), &schedule);
        env.storage().instance().set(&DataKey::NextId, &(id + 1));

        env.events().publish((Symbol::new(&env, "created"), id), (amount, interval));
        id
    }
```

## Checking if Due and Executing

```rust
    pub fn is_due(env: Env, schedule_id: u64) -> bool {
        let s: Schedule = env.storage().instance()
            .get(&DataKey::Schedule(schedule_id))
            .expect("not found");
        !s.paused
            && (s.remaining == 0 || s.executed < s.remaining)
            && env.ledger().timestamp() >= s.next_due
    }

    pub fn execute(env: Env, keeper: Address, schedule_id: u64) {
        // Anyone can call execute — keeper is logged in event but not privileged
        let _ = keeper;

        let mut s: Schedule = env.storage().instance()
            .get(&DataKey::Schedule(schedule_id))
            .expect("schedule not found");

        assert!(!s.paused, "schedule is paused");
        assert!(
            s.remaining == 0 || s.executed < s.remaining,
            "schedule completed"
        );
        assert!(
            env.ledger().timestamp() >= s.next_due,
            "not due yet"
        );

        token::Client::new(&env, &s.token).transfer(
            &env.current_contract_address(),
            &s.recipient,
            &s.amount,
        );

        s.executed += 1;
        s.next_due += s.interval;
        env.storage().instance().set(&DataKey::Schedule(schedule_id), &s);

        env.events().publish(
            (Symbol::new(&env, "executed"), schedule_id),
            (s.executed, s.amount),
        );
    }
```

## Pause and Cancel

```rust
    pub fn pause(env: Env, caller: Address, schedule_id: u64) {
        caller.require_auth();
        let mut s: Schedule = env.storage().instance()
            .get(&DataKey::Schedule(schedule_id))
            .expect("not found");
        assert!(caller == s.owner, "not your schedule");
        s.paused = true;
        env.storage().instance().set(&DataKey::Schedule(schedule_id), &s);
    }

    pub fn cancel(env: Env, caller: Address, schedule_id: u64) {
        caller.require_auth();
        let s: Schedule = env.storage().instance()
            .get(&DataKey::Schedule(schedule_id))
            .expect("not found");
        assert!(caller == s.owner, "not your schedule");
        env.storage().instance().remove(&DataKey::Schedule(schedule_id));
        env.events().publish((Symbol::new(&env, "cancelled"), schedule_id), ());
    }
}
```

## Off-Chain Keeper

```ts
import { Contract, SorobanRpc, TransactionBuilder, Networks, BASE_FEE } from "@stellar/stellar-sdk";

const server   = new SorobanRpc.Server("https://soroban-testnet.stellar.org");
const CONTRACT = "C...";

async function runKeeper(keeperKeypair: Keypair, scheduleIds: number[]) {
  for (const id of scheduleIds) {
    const due = await checkIsDue(id);
    if (due) {
      await executeSchedule(keeperKeypair, id);
      console.log(`Executed schedule ${id}`);
    }
  }
}

async function checkIsDue(scheduleId: number): Promise<boolean> {
  // Simulate call to is_due() and read the return value
  const result = await server.simulateTransaction(/* is_due call tx */);
  return /* decode bool from result.result.retval */;
}

async function executeSchedule(keeperKeypair: Keypair, scheduleId: number) {
  const account  = await server.getAccount(keeperKeypair.publicKey());
  const contract = new Contract(CONTRACT);
  const tx = new TransactionBuilder(account, { fee: BASE_FEE, networkPassphrase: Networks.TESTNET })
    .addOperation(contract.call("execute", /* keeper Address xdr, schedule_id u64 xdr */))
    .setTimeout(30)
    .build();

  const prepared = await server.prepareTransaction(tx);
  prepared.sign(keeperKeypair);
  return server.sendTransaction(prepared);
}

// Run every 5 seconds
setInterval(() => runKeeper(keeperKeypair, [0, 1, 2]), 5_000);
```

## Failure Handling

| Failure mode | What happens | Recovery |
|-------------|--------------|---------|
| Contract has no token balance | `transfer` fails; `execute` reverts | Owner deposits tokens; keeper retries |
| Keeper is offline | `next_due` passes without execution | Keeper calls `execute` when it recovers — the contract accepts any late call |
| Schedule expires (`executed >= remaining`) | `execute` asserts and reverts | Normal end of lifecycle; create a new schedule if needed |
| Accidental double execute | `next_due` already advanced; `timestamp < next_due` reverts | Safe by design |

---

## Accuracy Notes

- `env.ledger().timestamp()` advances with each ledger close (~5 seconds); minimum practical interval is ~30 seconds.
- The contract must hold token balance before any execution; fund it after deploying and before the first `next_due`.
- `remaining = 0` means unlimited; implement a maximum cap if you want to prevent runaway payments.
- Keepers should be incentivized (e.g. small fee paid per execution) to ensure reliable triggering in production.
