# Hook Composition for Complex Stellar Flows

In real-world dApps, user transactions rarely operate in isolation. Complex user journeys — such as swapping tokens, establishing trustlines on demand, or interacting with multi-contract Soroban dApps — require combining multiple React hooks. This guide presents patterns for hook composition, state synchronization, and resilience.

---

## 1. Composition Architectural Patterns

When chaining custom hooks (e.g., `useStellarWallet`, `useStellarBalances`, and `useSorobanContract`), follow these architectural principles:

- **Single Source of Truth**: Key state (like active wallet public key or network mode) should originate from a root wallet context or primary hook.
- **Pipeline Orchestration**: Encapsulate multi-step operations in higher-level domain-specific hooks rather than scattering async logic across UI components.
- **Declarative Dependencies**: Derive hook parameters directly from parent hook outputs to leverage React's reactive update lifecycle.

---

## 2. State Coordination & Race Conditions

Multi-step blockchain operations are subject to race conditions and stale UI states. Manage coordination using:

1. **Transaction Lifecycle Flags**: Maintain explicit status fields (`idle` | `trustline_pending` | `invoking_contract` | `success` | `failed`).
2. **Post-Transaction Cache Invalidation**: Explicitly call `mutate()` or `refresh()` on balance and state hooks immediately after transaction confirmation.
3. **Optimistic UI Updates**: Provide instant visual feedback while awaiting block inclusion, with rollback handlers on transaction revert.

---

## 3. Worked Example: Auto-Trustline & Contract Invocation Flow

This worked example demonstrates composing `useStellarWallet`, `useStellarBalances`, and `useSorobanContract` into a composite `useExecuteSorobanSwap` hook that automatically checks for required trustlines before contract invocation.

```typescript
import { useState, useCallback } from 'react';
import { useStellarWallet } from '@/hooks/useStellarWallet';
import { useStellarBalances } from '@/hooks/useStellarBalances';
import { useSorobanContract } from '@/hooks/useSorobanContract';

export function useExecuteSorobanSwap(tokenAssetCode: string, tokenIssuer: string) {
  const { publicKey, signTransaction } = useStellarWallet();
  const { balances, refreshBalances } = useStellarBalances(publicKey);
  const { invokeContract } = useSorobanContract(process.env.NEXT_PUBLIC_SWAP_CONTRACT_ID!);

  const [status, setStatus] = useState<'idle' | 'checking_trustline' | 'adding_trustline' | 'swapping' | 'success' | 'error'>('idle');
  const [errorMessage, setErrorMessage] = useState<string | null>(null);

  const executeSwap = useCallback(async (amount: string) => {
    if (!publicKey) throw new Error('Wallet not connected');

    setStatus('checking_trustline');
    setErrorMessage(null);

    try {
      // Step 1: State Coordination — Check if trustline exists
      const hasTrustline = balances.some(
        (b) => b.asset_code === tokenAssetCode && b.asset_issuer === tokenIssuer
      );

      // Step 2: Conditional Execution — Add trustline if missing
      if (!hasTrustline) {
        setStatus('adding_trustline');
        const trustlineTxXdr = await fetchTrustlineTxXdr(publicKey, tokenAssetCode, tokenIssuer);
        const signedTrustlineTx = await signTransaction(trustlineTxXdr);
        await submitTx(signedTrustlineTx);
        await refreshBalances(); // Invalidate stale state
      }

      // Step 3: Contract Invocation
      setStatus('swapping');
      const swapResult = await invokeContract('swap', {
        amount,
        user: publicKey,
      });

      setStatus('success');
      await refreshBalances();
      return swapResult;
    } catch (err: any) {
      setStatus('error');
      setErrorMessage(err.message || 'Swap operation failed');
      throw err;
    }
  }, [publicKey, balances, tokenAssetCode, tokenIssuer, signTransaction, invokeContract, refreshBalances]);

  return { executeSwap, status, errorMessage };
}
```

## 4. Helper API Placeholders

```typescript
async function fetchTrustlineTxXdr(account: string, code: string, issuer: string): Promise<string> {
  const res = await fetch(`/api/trustline?account=${account}&code=${code}&issuer=${issuer}`);
  const data = await res.json();
  return data.xdr;
}

async function submitTx(signedXdr: string) {
  const res = await fetch('/api/submit', {
    method: 'POST',
    body: JSON.stringify({ xdr: signedXdr }),
  });
  if (!res.ok) throw new Error('Transaction submission failed');
}
```
